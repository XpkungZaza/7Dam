# 🏛️ PROJECT ETADAM (PROJECT 7DAM) - AI AGENT COLLECTIVE PORTFOLIO

## 📌 Project Overview & Vision
This is a secret high-caliber portfolio project for university admission: **Project Etadam (Project 7Dam)**.
It is a modern, unified Web Hub designed to interface with 7 specialized AI Agents ("Eta Agents"), each assigned a Greek codename and dedicated domain.

---

   - **Status**: ACTIVE & Modularized (`Torine_AI/torine-config.js`)
   - **Tech**: Groq API (`llama-3.1-8b-instant`) + Web Speech Synthesis (`ja-JP`)

2. **Beta (Slot 02) - Z.E.N.I.T.H.**
   - **Full Name**: Zero-error Enhanced Navigational Intelligence & Trajectory Heuristics
   - **Domain**: Navigation, Trajectory Planning & Data Strategy
   - **Status**: IN PROCESS (`Zenith_AI/`)

3. **Gamma (Slot 03) - F.R.E.E.D.O.M.**
   - **Full Name**: Fault Recognition & Execution Engine for Debugging, Optimization & Maintenance
   - **Domain**: Software Engineering, Code Debugging & System Maintenance
   - **Status**: IN PROCESS (`Freedom_AI/`)

4. **Delta (Slot 04) - M.O.R.G.A.N.**
   - **Full Name**: Multi-Objective Robotic Grid & Autonomous Nexus
   - **Domain**: Robotics, Grid Networks & System Automation
   - **Status**: IN PROCESS (`Morgan_AI/`)

5. **Epsilon (Slot 05) - Agent 05**
